# last frame": it looks the caller's handle up in data_0209b53c and, finding
# it, marks the entry +6 and returns the same handle; finding nothing, it
# starts a new sound and hands back a new handle. Refresh, therefore, is the
# ONLY thing keeping a looping sound alive, and func_020119c8 is the other
# side of that contract. Once a frame it walks all 0x40 entries, clears the
# +6 flag on everything that was refreshed, and on everything that was not

# of the first, which was never stopped and never will be. Every wall slide,
# butt slide, hard turn and walk adds one more permanent copy of the same
# looping effect, summing louder each time.
# and the level-change half of the same contract. Scene::BeforeCleanupResources
# (vtable slot 4) fires func_02011974(&data_0209b53c) on every level change: it
# walks the same 0x40 entries as func_020119c8 but stops EVERY live handle,
# ignoring the +6 refreshed flag the per-frame reaper spares. The port keeps the
# Scene alive across levels so the slot never dispatches; hal/level_change.cpp
