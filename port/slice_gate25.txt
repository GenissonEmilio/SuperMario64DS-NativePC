# Gate-25 slice: THE BOTTOM SCREEN. (Renumbered from 24 at merge.)
#
# Everything the sub engine draws is already matched; what this slice adds is
# the code that puts bytes in front of it.
#
# 1. The OAM lifecycle the port never ran. OAM::Reset rebuilds both shadows at
#    the top of the 2D frame, the RenderSub pair is what HUD and Minimap emit
#    through, and OAM::EnableSubOAM is the one that clears data_0209e660 so a
#    sub==true sprite stops landing in the top screen's buffer. OAM::Load
#    itself reads POWCNT textually, so it comes through hostgen (GATE6_GEN),
#    and the two upload primitives it calls come from here.
#    The ten-argument OAM::Render core is already in slice_gate10, and
#    GetObjWidth/GetObjHeight/LoadAffineParams with it.
#
# 2. Stage::LoadGraphics2D and its closure: the function that fills the bottom
#    screen's BG character data, tilemaps and both palettes, plus the sprite
#    tiles at 0x6600000. Without it the sub engine scans out an empty VRAM and
#    the panel is one flat backdrop colour.
#
# 3. Stage::CheckCameraInput, which hit-tests the on-screen camera buttons
#    against the touch record and turns them into the same rotate bits the
#    shoulder buttons produce.
