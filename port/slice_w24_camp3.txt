# of port/faces_sync.txt instead. That face and this arm make the same two
# calls: the D1 body, then the row's own deallocation (Memory::Deallocate
# with the row's heap word, or Memory::operator_delete2), proved against
# config relocs by facegen's D0 rule and checked object-side by
# d0arm_check.py. The retired D rows are in port/faces_sync.txt, so exactly
# one definition of each flat name remains.
